# 当前课程数据

catalog.json：10章与54节顺序、稳定ID。
lessons.json：知识模块、函数链接、逐步原因与成功判据、示意、片段和排错。
functions.json：93个课程相关函数的声明、参数和关联小节。
questions.json：54道检查题与54张记忆卡；答案用选项ID而非位置。
source-register.json：来源名称、页数、指纹、工程版本与资料问题。
legacy-ids.json：旧章节和知识点的兼容白名单，仅用于导入，不恢复旧题库。

内容版本1.0.0-course；学习数据格式仍为v1。source_checked表示课程来源核对，不能等同官方完整包验证。教学代码仍未编译或实机验证。
