# 芯知 · STM32 标准库课程学习台

围绕STM32F103C8T6与标准外设库，按课程1.1—10.6组织10章、54节原创讲解。每节把知识、函数、操作原因、成功判据和练习串起来。

- 54节讲解、54道检查题、54张记忆卡。
- 93个课程相关标准库函数，可从步骤内展开原型与参数。
- 原创原理/时序示意、排错、函数搜索、错题与间隔复习。
- 手机优先，支持浅色与深色。

正式网站：https://1hx7826.github.io/stm32-review/

## 本地运行

使用Node.js 24 LTS：

```sh
cd web-app
npm ci
npm run dev
```

开发地址：http://127.0.0.1:5173/ 。

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

生产预览：http://127.0.0.1:4173/stm32-review/ 。端口占用可用 `npm run preview -- --port 4176`。构建需要同级content目录，生成内容不必提交。

## GitHub Pages

.github/workflows/deploy.yml只由main分支的workflow_dispatch手动触发，推送不会自动发布。工作流依次npm ci、类型检查、90项测试、生产构建/公开审计，然后上传web-app/dist并部署。

生产base为/stm32-review/；Hash路由支持刷新。仓库更名时修改web-app/vite.config.ts中的生产base，再运行测试/构建。

更新时核对公开白名单、逐路径暂存、审查差异后推送，再手动运行工作流。不要提交node_modules、dist、学习备份或原始参考资料。

## 本地学习记录

无需账号；学习记录保存在浏览器IndexedDB，主题保存在localStorage；应用不主动上传进度。跨设备用JSON导入导出；替换须先校验、预览、明确确认。旧v1备份保留兼容，原课程题目作为历史归档，不与新课程混算。

同一网址更新不会主动清空原数据库。不同设备、浏览器、域名或端口有独立存储，GitHub Pages不提供自动同步。清除站点数据会删除浏览器内的记录，建议定期导出。
